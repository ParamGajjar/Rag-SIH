# Vectorless RAG Application (PageIndex + LangGraph)

A clean, beginner-friendly Python application that implements **Vectorless Retrieval-Augmented Generation (RAG)** using document hierarchy trees instead of vector embeddings.

---

## 💡 What is Vectorless RAG?

Standard RAG breaks documents into chunks, turns them into numbers (embeddings), and searches vector databases using math similarity. 

**Vectorless RAG** uses tree-based reasoning instead:
1. Documents are converted into structured hierarchical trees (like an intelligent Table of Contents).
2. The LLM reads the tree structure to *reason* where the answer lives (e.g., "This topic belongs in Chapter 2, Page 14").
3. Only the exact pages needed are retrieved.

---

## 🛠️ Architecture Overview & Components

- **PageIndex**: Converts PDFs locally into tree structures without vector databases.
- **LangChain**: Interfaces with Primary and Fallback LLMs.
- **LangGraph**: Manages a simple 2-node workflow graph (`retrieve_documents` -> `generate_answer`).
- **OpenRouter (Primary)**: Cloud LLM provider (OpenAI-compatible).
- **Ollama (Fallback Local)**: Free, local LLM runner for complete privacy and offline support.
